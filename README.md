# Oppgave 1 - Lagstyringsprogram

Et Python-program for å administrere laguttak for miniturneringer i fotball og innebandy. Lar deg legge til/fjerne spillere og generere tilfeldige laguttak med 1 målvakt, 2 forsvarere, 2 angripere (pluss innbyttere).

## Funksjoner
- Legg til/fjern spillere
- Vis alle spillere
- Lag tilfeldig laguttak (minst 5 spillere)

## Krav
- Python 3.x

## Kjøring
1. Åpne terminal i VS Code
2. `cd "c:\Github\oppgave 1"`
3. `python "oppgave 1.py"`

## Bruk
Meny med valg 1-5:
1. Legg til spiller
2. Fjern spiller
3. Vis spillere
4. Lag laguttak
5. Avslutt

Spillere lagres i `spillere.txt`.
